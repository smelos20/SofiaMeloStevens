Connect to GitHub (one time)

This lets the Publish button save straight to your site. You only do this once per computer.

How to get your key
  1. Open GitHub → new fine-grained token (sign in if asked).
  2. Token name: Portfolio editor. Expiration: pick a custom date about a year out.
  3. Repository access: Only select repositories → SofiaMeloStevens.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Click Generate token, copy it, and paste it below.

The key stays only in this browser on this computer. Don't share it with anyone.

Help
  1. Text: click and type. Enter makes a new paragraph or bullet. Shift+Enter makes a line break.
  2. Images: click one, then Replace image. Big photos are shrunk automatically so the site stays fast.
  3. Moving things: click it, then Move up or Move down. To move a whole section, use "Select the bigger area".
  4. More bullets, facts or tags: click one and press Duplicate.
  5. Switching pages keeps your edits. Nothing is live until you press Publish.
  6. After publishing, the live site updates in about a minute. Refresh with Ctrl+Shift+R (Cmd+Shift+R on Mac).
