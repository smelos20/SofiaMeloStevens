How do I publish my changes?
  1. Download the page (and any new images or style.css) with the buttons above.
  2. Open your repo on github.com.
  3. For a page or style.css: click Add file → Upload files, drag the file in, and click Commit changes. A file with the same name replaces the old one.
  4. For images: open the images folder in the repo first, then Add file → Upload files.
  5. Wait 1 to 2 minutes, then refresh your site (Ctrl+Shift+R).

Your browser may ask to allow multiple downloads. Say yes.
